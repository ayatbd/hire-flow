## Project overview

- A modern hiring and recruitment platform designed for both job seekers and recruiters.
- Helps candidates discover jobs, explore companies, compare salaries, and manage their application journey.
- Gives recruiters tools to post jobs, review candidates, and manage hiring workflows from a dashboard.
- Includes role-based onboarding and authentication flows for different user types.
- Features profile management, resume upload, notifications, and personal settings to support a complete user experience.
- Built with a polished, responsive UI using Next.js, React, Tailwind CSS, and Redux-based state management.
- Structured around core sections like jobs, companies, salaries, recruiter dashboards, and seeker dashboards.
